Jarvis Desktop

Connect to your Jarvis server

1. Server address

Where jarvis serve is running. Default is this computer.

2. Pair this device

On the server run jarvis pair and type the 8-character code here. The device token is kept in your system keychain, never shown or sent anywhere else.

Audio

Bluetooth earbuds work well for listening, but using their microphone forces them into a call mode that can be silent on some computers. By default Jarvis listens through a non-Bluetooth microphone and speaks through the system default output. Changes apply to a running call within a second.
